# Recordings for everyone

A grown-up's own recordings of the games' lines go here, one file per line,
named with the line's number in the recording script
(`voice/script/recording-script.pdf`): `001.m4a`, `002.m4a`, `123.wav`...
Any common audio format works (phone voice memos, .wav, .mp3).

Adding files here on `main` (on GitHub: **Add file → Upload files** in this
folder) starts the "Make voice clips" workflow. It trims the silence, evens
out the loudness, and uses each recording in place of the AI voice for that
line, then republishes the site. Lines without a recording keep the AI
voice. To redo a line, upload a new file with the same number.
